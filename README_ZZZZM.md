# ZZZZM 策略（币安合约追涨）· Mac 部署

来源：github.com/fuya417061649/ZZZZM，回测结论见文末。已修两处。

## 与原版的差异

1. **仓位 bug 修复**（重要）：原版 `qty = max(1, int(max_value/price))` 会给高价币强制开 1 张整币仓位——ETH 价格 $3000 时计划 $90 却开出 ~$3000 名义（几十倍），回测实测一个 -5% 止损就亏 $150+。已改为 `qty = int(max_value/price)`，凑不够 1 张就跳过该币。
2. **代理可切换**：原版硬编码 SOCKS5 127.0.0.1:7891。现默认**直连**币安；如需代理，跑之前设环境变量：
   ```bash
   export BINANCE_PROXY=socks5://127.0.0.1:7891
   ```

## Mac 上运行

```bash
# 1. API Key（原版要求，先确认文件在）
cat ~/.binance/trading       # 内容: api-key=... / api-secret=...

# 2. 先跑一次看输出
python3 binance_strategy.py

# 3. 定时运行（每3分钟，原版节奏）
crontab -e
# 加一行：
*/3 * * * * cd ~/你的AI-23目录 && /usr/bin/python3 binance_strategy.py >> zzzzm.log 2>&1
```

⚠️ **先确认账户风控再上 cron**：策略每 3 分钟扫一次涨幅榜前 30，评分 ≥40 就开多（5~10x 杠杆），最多 6 仓。建议先手动跑几天看 `zzzzm.log`。

## 回测结论（2026-11-05 ~ 11-19，真实每日涨幅榜前30猎场）

| 版本 | 收益 | 胜率 | 盈亏比 PF | 最大回撤 |
|---|---|---|---|---|
| 原版（含仓位bug） | -16.6% | 23.2% | 0.36 | 17.8% |
| 修复仓位 | -13.2% | 23.0% | 0.42 | 14.6% |

**结构性短板**：125 笔里 78 笔死于「评分止损」，动态止盈门槛 5%~50% vs 移动止损 5~6% 互相打架——赢家被过早砍、输家拖到评分止损。选币/入场有效，出场端亏钱。实盘前建议：浮盈 >2% 时禁用评分止损、止盈门槛降到 3% 与移动止损对称。这两处改动涉及策略语义，为保持与原版一致未动，要改在 `analyze_position` 里调。
